# 开发、测试与构建说明

本文只描述本仓库中已验证或可复现的步骤。没有在本轮迭代中实际打出并验证 Windows 安装包，因此不提供“已在 Windows 上可安装”的结论。

## 环境

- Python 3.13（网关与契约测试）
- Node.js 24（身份/协议隔离与 supervisor 测试）
- 可选：pnpm（仅当需要从源码跑 ZCode 桌面，本文件不展开完整 Electron 打包）

不要提交 `agent-service/.env`、`agent-service/gateway.json` 或任何真实 API Key。

## 测试（与 CI 相同，已在本机跑通）

```bash
# 方式一：脚本
./scripts/run-tests.sh

# 方式二：分步
cd agent-service
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
pytest -q

# 回到仓库根目录
node --test tests/product-isolation.test.mjs tests/gateway-supervisor.test.mjs
```

这些测试全部走 mock / 契约，**不需要** DashScope、硅基流动或阿里云凭证。

## 启动网关（开发）

```bash
cd agent-service
source .venv/bin/activate
# 可选：cp gateway.example.json gateway.json
python run_gateway.py --host 127.0.0.1 --port 18765
curl -sS http://127.0.0.1:18765/healthz
```

设置页：http://127.0.0.1:18765/settings

默认拒绝绑定 `0.0.0.0`。若确需局域网访问，设置 `AGENT_GATEWAY_ALLOW_LAN=1`。
