## 云依赖处理
- 智谱/Z.ai 服务地址全部改为本地 `http://127.0.0.1:18765`，网关兜底路由返回 404 JSON（“disabled in AgentCore Desktop (offline)”），不会对外发起请求。
- 用量统计、营销 Banner、官方 MCP 配额、分享、插件市场、OAuth 登录：均指向本地桩 → 显示为空/不可用。
- 自动更新：默认关闭；设置 `AGENTCORE_UPDATE_URL`（generic feed）后启用。
- DNS 抓包：修复后运行期间未见 z.ai / bigmodel 查询（修复前 Web UI 曾查询 zcode.z.ai，来源已清理）。

## 已知限制
- 设置页依赖网关进程（首个会话启动时由 bridge 拉起）；网关未运行时页面显示“离线”。
- agentscope 后端无工具时为非流式输出。
- SiliconFlow 免费额度 TPM 较低，并发时会 429（会自动重试，但较慢）。

## 2026-11 迭代补充

- 默认应用身份、协议与家目录已与原版 ZCode 隔离（`com.agentcore.desktop` / `agentcore://` / `~/.agentcore-desktop`）。`AGENTCORE_DESKTOP_IDENTITY=0` 可回退。
- 网关提供 `/admin/presets` 中文预设（mock / 硅基流动 / 百炼 / OpenAI 兼容 / AgentCore / AG-UI）。预设和示例配置不含密钥。
- `/healthz` 含 `last_error`；上游 401/429/连接失败返回中文；默认禁止绑定 `0.0.0.0`。
- 官方插件市场文案改为「官方插件市场已离线禁用」（设置项与入口标签）。本地 MCP / Skills 仍可用。
- **未实测：** AgentScope、阿里云 AgentCore、真实硅基流动/DashScope 端到端对话（缺 API Key / 云凭证时只跑 mock 与契约测试）。
